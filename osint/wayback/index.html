    Fitur Wayback Machine yang tersedia di sini

    Ringkasan & Skyline 3DJumlah tangkapan per bulan/tahun, tangkapan pertama & terakhir.
    KalenderHeatmap tangkapan per hari, daftar tangkapan per hari, pratinjau & versi mentah.
    Perubahan (Changes)Versi konten unik, grafik ukuran, dan diff teks antar-versi.
    URLSemua URL arsip di bawah domain/host/prefix, filter tipe & status, ekspor TXT/CSV/JSON.
    Peta SitusSunburst struktur situs berdasarkan path URL yang diarsipkan.
    SubdomainHost yang pernah muncul di arsip beserta jumlah URL & tanggal pertama.
    Temuan OSINTrobots.txt lama, parameter URL, dokumen, backup, konfigurasi, endpoint API, panel admin.
    Mesin waktu & Save Page NowLompat ke tangkapan terdekat dari tanggal tertentu, atau minta arsip baru.

    Data diambil langsung oleh browser Anda dari API Wayback Machine (Availability API & CDX Server) milik Internet Archive. Situs ini statis: tidak ada server, tidak ada yang disimpan. Wayback membatasi jumlah permintaan; jika muncul galat 429, tunggu sebentar. Gunakan secara bertanggung jawab — untuk riset, jurnalisme, keamanan situs milik sendiri, atau pengujian yang diizinkan.
